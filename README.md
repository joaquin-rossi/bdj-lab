# bdj-lab

[![CI](https://github.com/joaquin-rossi/bdj-lab/actions/workflows/ci.yml/badge.svg)](https://github.com/joaquin-rossi/bdj-lab/actions/workflows/ci.yml)

Tools for building Blu-ray discs with BD-J (Java) menus.

- [`bd-build`](bd-build/): builds a disc image from a `bd.yaml`.
- [`udf-image`](udf-image/): writes UDF 2.50 images.
- [`demo`](demo/): an example disc.
